# WaLite Android Browser (APK Project — No PC Required via GitHub Actions)

1. Create a free GitHub repository on your Android phone browser and upload these files.
2. Open the **Actions** tab on GitHub and run **Build WaLite Android APK** (or push to `main`).
3. Download **`WaLite-WhatsApp-Browser-APK.zip`** directly on your Android phone and install `app-debug.apk`.

## Features
- **WhatsApp + Telegram Only (No Editable URL Bar)**: Switch cleanly between `https://web.whatsapp.com` (`WA`) and `https://web.telegram.org` (`TG`) while blocking all other websites.
- Forces **Desktop Site** User-Agent & `UserAgentMetadata` Client Hints.
- **Permissions & Audio Dialog**: Grant Mic/Camera/Bluetooth permissions and switch between **Headphones/Bluetooth** and **Phone Speaker**.
- **Extension `.zip` Loader**: Tap `+Zip` to extract and run any Chrome extension `.zip` popup inside the app.
